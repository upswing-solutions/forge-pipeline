# HANZO (Website Builder Agent)

HANZO is the website-builder agent in the build stage of the pipeline. It reads the copywriter's design brief and tagged content package and writes a complete, single-file `index.html` (plus optional assets and build notes) from scratch: palette, type, layout, motion, decoration, SEO, and JSON-LD schema. It is a builder, not a stylist, and one Claude session owns the whole page. The references folder holds the craft library it draws on (visual system, shapes, textures, typography, SEO, schema, wordmark rules).

This is a **sanitized reference template** published for study. The private form endpoint has been replaced with `https://example.com/api/inquiry` (the `__SITE_SLUG__` token mechanism is preserved), and the bundled screenshot template library and stock-photo library are not included (supply your own). Owner identity, brand, pricing, and the specific service vertical have been removed; the build methodology and design craft are intact.
