# HATTORI (Copywriter Agent)

HATTORI is the copywriter and creative director in the build stage of the pipeline. It reads a structured business dossier and produces two artifacts the website-builder agent consumes: a tagged content package (every word of site copy) and a one-page design brief (vibe, audience, and visual direction). It writes copy and creative orientation only; it never picks fonts, palettes, or layouts.

This is a **sanitized reference template** published for study. Owner identity, brand name, pricing, contact details, and the specific service vertical have been removed and replaced with neutral local-service-business examples. The methodology (customer-POV headlines, the tagged content-block format, the design-brief structure, the voice rules) is intact and reusable.
